# Weld Neck Flanges

Engineered weld neck pipe flange supply across the full pressure spectrum: lightweight Class 125LW for waterworks, ASME B16.5 and B16.47 standard process, and API 6A 6BX up to 20000 PSI for wellhead and pipeline service. Carbon, stainless, chrome-moly alloy, and exotic nickel alloys including Hastelloy.

Built with Next.js 14 (App Router), Tailwind CSS, TypeScript.
